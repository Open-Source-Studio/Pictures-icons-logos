# Pictures Icons Logos

Коллекция логотипов, иконок и графических ресурсов для использования в проектах.

## 📁 Структура проекта

```
Pictures-icons-logos/
├── social-networks-logo/     # Логотипы социальных сетей
│   ├── logo-telegram.png    # Telegram (1024x1024)
│   └── telegram-logo.png    # Telegram (512x512)
└── README.md
```

## 🖼️ Доступные ресурсы

### Социальные сети

| Платформа | Размеры | Форматы | Файл |
|-----------|---------|---------|------|
| Telegram  | 1024x1024 | PNG | `logo-telegram.png` |
| Telegram  | 512x512 | PNG | `telegram-logo.png` |

## 📋 Использование

### Быстрый доступ

```bash
# Клонировать репозиторий
git clone https://github.com/Open-Source-Studio/Pictures-icons-logos.git

# Перейти в директорию
cd Pictures-icons-logos
```

### Прямые ссылки

```html
<!-- Telegram логотип 1024x1024 -->
<img src="social-networks-logo/logo-telegram.png" alt="Telegram" width="64" height="64">

<!-- Telegram логотип 512x512 -->
<img src="social-networks-logo/telegram-logo.png" alt="Telegram" width="32" height="32">
```

## 🤝 Участие в проекте

Мы приветствуем вклад в развитие коллекции!

### Правила добавления ресурсов

1. **Качество:** Минимальное разрешение 256x256 для иконок
2. **Формат:** Предпочтительно PNG или SVG
3. **Именование:** `[название]-logo.[расширение]` или `logo-[название].[расширение]`
4. **Права:** Убедитесь в законности использования

### Как добавить ресурс

1. Fork этого репозитория
2. Создайте новую ветку (`git checkout -b add-new-logo`)
3. Добавьте файлы в соответствующую директорию
4. Обновите README.md с информацией о новом ресурсе
5. Создайте Pull Request
