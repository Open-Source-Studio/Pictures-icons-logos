# Лицензия и условия использования

## Общие положения

Данный репозиторий содержит коллекцию логотипов, иконок и графических ресурсов. Все материалы предоставляются "как есть" исключительно для образовательных и информационных целей.

- **Telegram:** Логотип Telegram является торговой маркой Telegram FZ-LLC
- Все права на торговые марки принадлежат их соответствующим владельцам

### ✅ Разрешенное использование

- Использование в образовательных проектах
- Использование в некоммерческих проектах с указанием источника
- Использование для демонстрации интеграций с соответствующими платформами

### ❌ Запрещенное использование

- Коммерческое использование без разрешения правообладателей
