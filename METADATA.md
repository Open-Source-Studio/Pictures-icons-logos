## Стандарты качества

### Размеры
- **Иконки:** 16x16, 32x32, 64x64, 128x128, 256x256
- **Логотипы:** 256x256, 512x512, 1024x1024
- **Высокое разрешение:** 2048x2048 и выше

### Форматы
- **PNG:** Для логотипов с прозрачностью
- **SVG:** Для векторных изображений (предпочтительно)
- **JPG:** Только для фотографических изображений

### Оптимизация
- Сжатие без потери качества
- Удаление метаданных EXIF
- Оптимизация палитры для PNG-8
