# Руководство по участию в проекте

Спасибо за интерес к проекту Pictures Icons Logos! Мы приветствуем вклад сообщества в развитие коллекции графических ресурсов.

## 🎯 Цели проекта

- Создание качественной коллекции логотипов и иконок
- Обеспечение легального и этичного использования ресурсов
- Поддержание высоких стандартов качества и организации

## 📋 Требования к контенту

### Общие требования

1. **Качество изображений**
   - Минимальное разрешение: 256x256 пикселей
   - Четкие, контрастные изображения
   - Отсутствие артефактов сжатия

2. **Форматы файлов**
   - Предпочтительно: PNG (с прозрачностью)
   - Приемлемо: JPG (только для фотографий)
   - Желательно: SVG (для векторных логотипов)

3. **Права использования**
   - Убедитесь в законности использования
   - Предпочтение открытым лицензиям
   - Обязательное указание источника

### Организация файлов

#### Структура директорий

```
Pictures-icons-logos/
├── social-networks-logo/     # Социальные сети
├── tech-companies-logo/      # IT компании
├── programming-languages/    # Языки программирования
├── operating-systems/        # Операционные системы
├── browsers-logo/           # Браузеры
└── misc-icons/              # Разное
```

#### Именование файлов

**Для логотипов:**
- `[название]-logo.[расширение]`
- `logo-[название].[расширение]`

**Примеры:**
- `telegram-logo.png`
- `facebook-logo.svg`
- `logo-google.png`

**Для иконок:**
- `[название]-icon.[расширение]`
- `icon-[название].[расширение]`

## 🛠️ Процесс участия

### 1. Подготовка

1. Сделайте Fork репозитория
2. Клонируйте свой fork:
   ```bash
   git clone https://github.com/[ваш-username]/Pictures-icons-logos.git
   cd Pictures-icons-logos
   ```
3. Создайте новую ветку:
   ```bash
   git checkout -b add-[название-ресурса]
   ```

### 2. Добавление контента

1. Поместите файлы в соответствующую директорию
2. Убедитесь в соответствии именования стандартам
3. Оптимизируйте изображения (при необходимости)

### 3. Документация

Обновите `README.md`:

1. Добавьте запись в соответствующую таблицу
2. Укажите размеры, форматы и описание
3. Обновите статистику проекта

**Пример записи:**

```markdown
| GitHub | 1024x1024, 512x512 | PNG, SVG | `github-logo.png`, `github-logo.svg` |
```

### 4. Создание Pull Request

1. Сделайте commit с описательным сообщением:
   ```bash
   git add .
   git commit -m "Add GitHub logo in PNG and SVG formats"
   ```

2. Отправьте изменения:
   ```bash
   git push origin add-github-logo
   ```

3. Создайте Pull Request с описанием:
   - Что добавлено
   - Источник ресурсов
   - Подтверждение легальности использования

## ✅ Чек-лист перед отправкой

- [ ] Файлы правильно именованы
- [ ] Размещены в корректной директории
- [ ] README.md обновлен
- [ ] Указан источник и права использования
- [ ] Нет дублирования существующих ресурсов

## 🚫 Что НЕ принимается

1. **Нарушение авторских прав**
   - Логотипы без разрешения на использование
   - Модифицированные логотипы брендов

2. **Низкое качество**
   - Размытые или пикселизированные изображения
   - Изображения с артефактами
   - Неподходящие пропорции

3. **Неподходящий контент**
   - Оскорбительные изображения
   - Политические символы
   - Материалы для взрослых

## 🔍 Процесс рецензирования

1. **Автоматические проверки**
   - Размер файлов
   - Формат изображений
   - Структура директорий

2. **Ручная проверка**
   - Качество изображений
   - Соответствие стандартам
   - Легальность использования

3. **Обратная связь**
   - Комментарии к PR
   - Запросы на изменения
   - Одобрение или отклонение
